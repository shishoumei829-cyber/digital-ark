# 数字方舟 · 伦理与安全设计

> **原则：透明是前提，温暖是体验；陪伴有始有终，训练从轻开始。**

---

## 1. 知情同意（P0）

### 产品立场

陪护端用户**始终知道**对面是数字分身，不是真人实时在线。  
体验可以温暖、自然、有力量——就像读一封遗书，明知来源，仍会动容。

### 实现

| 机制 | 说明 |
|------|------|
| 首次进入 | 不可跳过知情同意屏，勾选「我理解这是数字分身」 |
| 持久标识 | 顶部栏显示「数字分身」徽章 |
| 授权 | 训练者逐人授权，可撤销 |
| Prompt | 第一人称；若被直接问起，诚实说明是数字分身，不冒充真人实时在场 |
| 本地记录 | `localStorage` + 服务端 `consent_records.json` 双存 |

---

## 2. 心理健康与哀伤（P1）

### 渐进淡出

默认启用「哀伤陪伴模式」，主动频率随时间递减：

| 阶段 | 时长 | 主动频率 |
|------|------|----------|
| 陪伴期 | 0–3 月 | 100% |
| 过渡期 | 4–6 月 | 70% |
| 留存期 | 7–12 月 | 40%，偏纪念日 |
| 封存期 | 12 月+ | 仅被动回应 / 可封存 |

训练者可在训练端配置起始日与各阶段参数。

### 依赖信号（非诊断）

启发式检测：高频对话、深夜使用、 distress 关键词。  
**不切断对话**，插入温和资源提示，建议联系现实中的人。

### 完成仪式

训练者可预设告别语，在淡出末期由数字分身说出一次。

## 3. 训练者心理负担（P1）

| 机制 | 说明 |
|------|------|
| 随手记 | 默认入口，一行字/一段语音即可，无分类压力 |
| 今天到此为止 | 点击后当日不再推送训练提醒 |
| 深度门禁 | 情感/遗愿/冲突等模块前询问「准备好了吗？」 |
| 会话缓冲 | 完成沉重模块后显示休息提示 |

---

## 4. 真实感缺口（P2）

- **低能量日**（约 8% 概率）：「今天不太想多说，但想到你了」
- **回复长度波动**：低能量时更短
- **非即时感**：偶尔延迟 0.5–2 分钟再回复（模拟在忙）
- 允许训练者录入「状态不好时通常怎样说话」

---

## 6. 法律与伦理边界（产品声明）

- 本产品为**数字遗产 / 知情陪伴**工具，不用于冒充他人在场或欺骗第三方。
- 系统不提供医疗或心理诊断； distress 提示仅作资源引导。
- 训练者对其授权对象及素材内容负主要责任；可随时撤销授权与删除数据。
