# 训练流程 UX v2 设计

## 问题
- 默认进入艾莉莎演示人格
- 训练页进度数据不一致（静态 68% / 0% 与真实 API 脱节）
- 「数字分身如何形成」与「专项深化」重复、需长滚动
- 记忆题：重复教练文案、只有跳过、细节字段打击回忆意愿

## 方案
1. **默认 `user` 人格**，仅演示模式加载 alisa-kujo
2. **训练页一屏**：完成度 + 五模块入口 + 今日继续 + 折叠说明
3. **答题统一三按钮**：提交 / 有印象 / 跳过
4. **记忆题**：题目置顶；细节收进「补充细节（可选）」；支持同题多条「再记一条」
5. **轮播题隐藏**「为什么做/怎么答/示例」教练块
