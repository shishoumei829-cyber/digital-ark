## 实施顺序（当前 Sprint）

1. **P0-1 ~ P0-4** — 进度体系 + 盲测 + UI 进度条
2. **M-1 ~ M-2, R-1 ~ R-3** — 记忆分层 + 关系建档 + 场景库
3. **A-1 ~ A-3, A-8** — 主动性引擎 v1
4. **CP-1, CP-2, CP-6** — 陪护消息卡片 + 对话归档
5. **C-2** — 冲突决策场景库扩展
6. 后续 Phase 按上表逐项推进
