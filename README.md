# 数字方舟

> 有情感连续性的本地数字分身训练与陪护系统

## 项目简介

数字方舟是一个**AI伴侣产品形态的实验性雏形**，旨在验证：
> 在本地、私密、可长期运行的前提下，AI能否形成「私人化、主动性、有情感连续性」的数字分身——而不是一次性工具调用。

## 核心功能

### 训练系统
- **音色训练**: 语音录制和分析，学习用户的说话方式
- **记忆训练**: 输入人生片段、照片，建立个人记忆库
- **关系训练**: 场景化测试，学习用户的关系处理模式
- **情感训练**: 情绪回应练习，学习用户的情感表达方式
- **认知训练**: 价值观排序和冲突决策，学习用户的思维方式

### 陪护系统
- **情感陪伴对话**: 文字/语音对话，提供情感支持
- **主动问候**: 空闲时主动开口，延续关系
- **隐私授权**: 管理谁可以访问数字分身
- **关系设置**: 配置陪伴偏好和安静时段

### 状态系统
- **PAD情感状态**: 愉悦度、唤醒度、支配度、关系强度
- **记忆系统**: 事件、时间线、观察、模式
- **策略层**: 跨轮次的相处策略
- **行为决策**: 多路径行为候选和打分选择

## 快速开始

### 前置要求
- Node.js v16+
- Ollama (本地运行)

### 安装

```bash
# 克隆项目
cd digital-ark

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置Ollama地址等

# 启动Ollama（如果未运行）
ollama serve

# 下载模型（如果需要）
ollama pull kurisu:latest
```

### 启动

```bash
# Web 版
npm start
# 或双击 启动.bat

# 桌面版（Electron 常驻窗口 + 托盘）
# 首次需：双击 安装桌面版.bat  或  npm run install:electron
npm run desktop
# 或双击 digital-ark/启动桌面版.bat（未装 Electron 时自动回退浏览器模式）

# 打包 Windows 安装包
npm run build:desktop
```

访问 http://localhost:3000

### Phase 2 能力

- **RAG 记忆检索**：Ollama embeddings（降级本地向量），对话时自动检索相关记忆
- **真实音色分析**：麦克风录音 + Web Audio 特征提取 + 声纹基线比对
- **TTS 语音播报**：优先 GPT-SoVITS，降级浏览器 SpeechSynthesis
- **数据备份**：导出/导入 gzip 备份，每日凌晨 3 点自动备份
- **敏感数据加密**：AES-256-GCM 加密 event_log 等文件

## API接口

### 对话接口
- `POST /chat` - 主对话接口

### 训练接口
- `POST /training/voice` - 语音训练
- `POST /training/memory` - 记忆训练
- `POST /training/relationship` - 关系训练
- `POST /training/emotion` - 情感训练
- `POST /training/cognition` - 认知训练
- `GET /training/progress` - 获取训练进度

### 陪护接口
- `POST /companion/chat` - 陪护对话
- `GET /companion/status` - 获取陪护状态
- `POST /companion/settings` - 更新陪护设置
- `GET /companion/greeting` - 获取主动问候

### 状态接口
- `GET /pad-state` - 获取PAD情感状态
- `GET /internal-state` - 获取完整内部状态
- `GET /user-model` - 获取用户模型
- `GET /memory` - 获取记忆数据
- `GET /health` - 健康检查

## 设计原则

- **LLM负责语言生成**: Ollama负责对话内容的生成
- **系统负责认知状态**: 情绪、记忆、策略、行为由系统管理
- **本地优先**: 数据默认存储在本地，保护用户隐私
- **模块化设计**: 各模块独立，便于扩展和维护
